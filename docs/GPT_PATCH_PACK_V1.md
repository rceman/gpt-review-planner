GPT Patch Pack v1 is retained only as immutable historical documentation. It
is not an active schema, builder, runner, template, validator, reader, or
fallback path in workflow 2.0.0.

New tasks MUST use the data-only GPT Patch Pack v2 contract documented in
[`templates/gpt-patch-pack-v2/README.md`](../templates/gpt-patch-pack-v2/README.md)
and [`docs/PATCH_PACK_FORMAT.md`](PATCH_PACK_FORMAT.md). Historical v1 commits
and evidence are not interpreted by current tooling.
